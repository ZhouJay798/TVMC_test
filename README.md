# TVMC：文件加密、2-of-5 可验证秘密共享与身份知识证明

Python 3.12 本地实验项目，验证任意两方恢复与异常拒绝，输出耗时和证据大小。

## 运行

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python demo.py
# 使用自己的文件：
.venv/bin/python demo.py /path/to/file --output artifacts/my-run
```

`artifacts/report.json` 包含全部 10 种两方组合的逐项恢复正确性、证明生成与认证恢复耗时、攻击拒绝结果和二进制证据大小。`encrypted.json` 包含密文、GCM 参数及公开承诺。默认输入为 47,104 字节。输出目录会覆盖同名实验结果；不要把输入放在输出文件位置。

## 协议

- 随机 P-256 标量作为秘密材料，经 HKDF-SHA256 派生 AES-256 密钥；AES-GCM 使用随机 96 位 nonce、128 位标签并认证协议元数据。
- 在 P-256 群阶域上使用一次多项式 `f(x)=s+a*x`，参与方编号为 1–5。任意两份通过拉格朗日插值恢复秘密材料。
- Feldman 承诺 `C0=sG, C1=aG`；验证 `share*G == C0 + index*C1`。先校验所有输入份额，再恢复；拒绝不足两份、重复编号、越界或篡改份额。
- 独立随机身份私钥对应预注册公钥。Schnorr Fiat–Shamir 知识证明绑定身份编号、公钥、承诺、文件摘要和验证者 256 位一次性挑战。验证者消耗挑战，认证通过后才在集成流程中恢复文件。
- `recover` 是不带身份认证的密码学底层函数；需要访问控制时调用 `Verifier.authenticate_and_recover`。

## 实验边界

这是协议研究原型，未经过安全审计。Python 的标量运算不保证常数时间；Feldman 承诺提供基于离散对数假设的计算隐藏性，并非信息论隐藏。单份测试验证接口拒绝，不能作为密码学安全证明。

演示在同一进程模拟五方与可信分发者；身份知识证明只证明持有预注册私钥，不证明现实世界身份。真实部署还需要可信公钥注册、认证传输、承诺来源认证、独立份额保管、挑战过期及持久化/分布式原子消费。当前挑战状态仅保存在内存中，重启后旧挑战不被接受。

密钥、份额和身份私钥只在内存中使用，不写入实验报告；进程结束后，输出密文不能单独恢复。该工具用于完整流程实验，不是持久化文件保管工具。整个文件读入内存，尚未提供流式大文件处理。

耗时是本机单次实验的墙钟时间，不代表统计基准；证据大小按未压缩 P-256 点（65 字节）、标量（32 字节）、份额编号（1 字节）计算，不包含 JSON/传输包装。Schnorr 证明为 97 字节，文件级 Feldman 承诺为 130 字节；注册公钥、nonce、上下文摘要单独统计。

## 测试

标准库 unittest 覆盖全部 10 个认证恢复组合、空文件与二进制、单份/重复/越界/篡改份额、密文/nonce/tag/承诺篡改、身份冒用、上下文替换、证明篡改、旧挑战重放与跨新挑战重放。CI 使用相同依赖和命令。
