# Tardos LoRA 指纹：真实 SmolLM2 CPU 实测记录

这是本仓库代码在真实 SmolLM2-135M 基座上的单次实验，不是小模型单元测试。秘密触发文本、码字、码本种子和原始响应未提交仓库。完整报告与适配器保存在云端被忽略的 `artifacts/tardos-cpu26-validation/`；本地需要按操作说明重新运行。

## 实验条件

- 模型：`HuggingFaceTB/SmolLM2-135M`，版本 `93efa2f097d58c2a74874c7e644dbc9b0cee75a2`。
- 权重 SHA-256：`80521b40281d6ce74e35c9282c22539e75aa0ac8578892b2a59955ef78d55da1`。
- 数据：WikiText-2 raw，版本 `b08601e04326c79dfdd32d625aee71d232d685c3`；train 用于保持损失、test 用于评估。
- CPU、float32、4 线程；3 个独立 LoRA 会话，每会话 200 步，32 位 Tardos 码，rank=8，q_proj/v_proj，学习率 0.001。
- 指纹 batch=4，自然文本 batch=1，保持损失权重 0.5；训练文本截取 16384 token，评估截取 4096 token，块长 128。
- 实际评估预测 token 数：4064，不计各块首 token。
- PyTorch `2.6.0+cpu`、Transformers `4.51.3`、PEFT `0.15.2`、NumPy `2.5.4`、Accelerate `1.15.0`；依赖文件与实际验证版本一致。

## 结果说明

- 综合实验门限是否通过：**True**。门限为错误/擦除合计不超过 10% 且归属正确，以及 PPL 增幅不超过 10%。
- 每会话可训练参数量：460,800。
- 三个会话的初始冻结参数哈希是否相同：True。
- 所有会话冻结基座保持不变：True；LoRA 参数发生变化：True。
- 另启新进程运行 `fingerprint.py read`，基座与三个会话合计 128 条生成响应均与原记录完全一致。
- 所有读取均在适配器保存、重新加载后进行。运行命令正常完成与质量门限通过是两个独立结果。
- PPL 下降仅说明这一 WikiText 测试子集上的语言建模表现改善，可能受同领域保持训练影响，不能推断其他能力全部改善。
- 训练时间不含下载、加载、哈希、保存及评估；RSS 是整个进程每 20ms 采样的峰值，不是适配器大小或严格系统峰值。
- 这是一次随机码本实验；未建立统计误报阈值，未验证合谋与擦除攻击鲁棒性。

操作命令、指标定义和复现方法见 [完整说明](TARDOS_FINGERPRINT.md)。
